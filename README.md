# Web Projects

[Portfolio](https://web-projects-portfolio.netlify.app)

Zbiór małych projektów webowych stworzonych w celu rozwijania umiejętności w HTML, CSS i JavaScript.

## Projekty

1. [Button Design](./button-design/README.md)

   - Różne style i animacje przycisków wykonane w CSS.

2. [Hangman](./hangman/README.md)

   - Implementacja gry "Wisielec" w JavaScript.

3. [Memory Gwint](./memory-gwint/README.md)

   - Gra pamięciowa inspirowana kartami z gry "Gwint".

4. [Portfolio](./portfolio/README.md)

   - Osobista strona portfolio prezentująca projekty i umiejętności.

5. [Today](./today/README.md)

   - Aplikacja wyświetlająca aktualną datę i godzinę z dodatkowymi funkcjami.

6. [Weather Forecast](./weather-forecast/README.md)
   - Aplikacja pogodowa pobierająca dane z zewnętrznego API.
